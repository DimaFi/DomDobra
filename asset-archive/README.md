# Архив заменённых файлов

В этой папке хранятся прежние версии изображений, заменённые на сайте.

Она расположена вне `src` и `public`, поэтому Vite не включает её содержимое в папку сборки `dist`. На хостинг загружается только содержимое `dist` после команды `pnpm build`.

При следующей замене изображения прежний файл следует переносить в `asset-archive/replaced-assets`, а новый подключать из `src/assets`.
