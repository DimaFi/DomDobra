МИНИМУМ ТЕКСТА — МАКСИМУМ ПОНЯТНОЙ ИНФОРМАЦИИ.

Сайт должен выглядеть:
— современно;
— минималистично;
— дорого, но не пафосно;
— тепло;
— спокойно;
— взрослым и серьёзным;
— визуально лёгким;
— не похожим на больницу;
— не похожим на типовой медицинский шаблон.

Все тексты сайта должны быть НА РУССКОМ ЯЗЫКЕ.

МАСШТАБ
==================================================

Это КРИТИЧЕСКИ ВАЖНО.

Сделай контент ЗНАЧИТЕЛЬНО КРУПНЕЕ, чем на стандартных лендингах.

Не пытайся уместить весь сайт на один экран или сделать всё мелким.

Каждый смысловой блок должен занимать много вертикального пространства.

Пользователь постепенно прокручивает сайт вниз.

Пример:

почти 90–100vh.

Следующий раздел:
60–80vh.

Следующий:
70–90vh.

Между секциями много воздуха.

Заголовки крупные.

Обычный текст также должен легко читаться.

НЕ использовать маленький текст.

При этом текста должно быть ОЧЕНЬ МАЛО.

Если информацию можно выразить:
— одним заголовком;
— цифрой;
— иконкой;
— 1 короткой фразой,

не добавляй абзац.

==================================================
ВЕТКИ / ЛОЗА
==================================================

Это одна из главных особенностей сайта.

Используй прикреплённые изображения отдельных веток на прозрачном фоне.

Ветки должны продолжать визуальную идею дерева из Hero.

НО:

не делать огромное дерево на всю страницу после Hero.

После первого экрана дерево постепенно переходит в небольшую декоративную лозу.

Между следующими большими секциями появляются небольшие ветви.

Принцип:

первая секция:
ветка выходит немного СЛЕВА;

следующая:
ветка появляется СПРАВА;

следующая:
снова СЛЕВА;

следующая:
СПРАВА.

Чередовать.

Ветки не должны закрывать контент.

Они работают как визуальные разделители между блоками.

Пример:

        SECTION

🌿────────

        SECTION

                    ───────🌿

        SECTION

🌿───────

        SECTION

Ветки должны выглядеть естественно и продолжать одну визуальную историю.

==================================================
АНИМАЦИОННАЯ КОНЦЕПЦИЯ
==================================================

Предусмотри дизайн так, чтобы потом на реальном сайте можно было сделать красивые scroll animations.

Первый экран:

при загрузке:
1. появляется заголовок;
2. появляется дерево;
3. листья немного раскрываются;
4. арка / дом проявляется;
5. CTA появляется последним.

При прокрутке:

контент должен появляться СНИЗУ ВВЕРХ.

Очень мягко:

opacity 0 → 1
translateY 40px → 0

Отдельные элементы появляются с небольшой задержкой.

Между секциями ветки должны визуально как будто «вырастать»:

линия ветки появляется первой,
затем маленькие листья.

Не делать мультяшную анимацию.

Не делать bounce.

Не делать резкие движения.

Не делать вращение элементов.

Общее ощущение:
premium smooth scroll.
